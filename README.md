# 弹幕躲避 · Dodge

一款单文件、可直接运行的弹幕躲避小游戏。双击 `index.html` 即可在浏览器中游玩，无需安装、无需联网。

## 🎮 玩法
- 移动鼠标 / 手指拖动，控制屏幕下方发光的蓝球
- 在密集弹幕中存活，越久得分越高
- 每关约 12 秒自动升级，弹幕种类变多、速度变快
- 被任意一颗子弹碰到即游戏结束
- 出生时有 2 秒无敌闪烁

## 🔫 弹幕类型
| 类型 | 说明 |
|------|------|
| 🔴 暴雨 | 顶部随机下落 |
| 🟣 螺旋 | 中心旋转射出 |
| 🟠 扫射 | 左右横扫的弹幕墙 |
| 🟢 追踪 | 瞄准玩家发射 |
| 🔵 环状 | 中心爆发的圆环 |

## 🏆 功能
- 关卡递进，难度平滑上升
- 本地最高分记录（`localStorage`）
- PC 鼠标 + 手机触摸双端适配

## 📦 分享给好友
1. 把整个文件夹压缩成 zip，微信「+ → 文件」发送，好友解压后双击 `index.html` 即可玩
2. 或部署到 Vercel / GitHub Pages，得到一个链接，发到群里点开即玩

## 🛠 自定义
- 修改 `state.player.r` 相关：调整玩家大小
- 修改 `buildLevel` 中 `nextLevelAt`：调整每关时长
- 修改各类 spawn 的 `interval` / `speed`：调整弹幕密度与速度
